# Hospital-Emergency-Room-Dashboard-Power-BI-
A powerful and interactive Power BI dashboard designed to deliver comprehensive insights into Emergency Room (ER) operations over a span of 19 months (April 2023 – October 2024), covering data from 9,216 unique patients. This project showcases real-world healthcare analytics capabilities, with a focus on patient flow, departmental referrals.
